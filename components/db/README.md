# Database component

Install all dependencies and extras with `uv sync --all-extras`.

## Creating migrations

To create migrations modify database models first.
Make sure to have the models imported in [env.py](./migrations/env.py)
by adding them into [models.all](./src/pinta_db/models/all.py) module.

After models for the target database have been modified, run the following command with the suitable path to alembic.ini file:

```bash
uv run alembic -c migrations/<job|main>/alembic.ini revision --autogenerate -m "Migration description" --rev-id="migration_id"
```

This command will generate a new migration file for the target database based on the changes made to the models.

Check the created migration file and make sure it is correct and remove Alembic autogenerated
comments from the top and bottom of the functions. Remember to commit it in the repository.

## Running migrations

To run migrations and sync users in development, in the root of the project run:

```bash
make db-migrate-all
```

or just run migrations in this directory:

```bash
uv run alembic -c migrations/<job|main>/alembic.ini upgrade head
```
