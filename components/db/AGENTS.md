# Agent Instructions — db

Models, Alembic migrations and DB utilities for two PostgreSQL/PostGIS databases:
`primary` (`pinta_db.primary_db`) and `job` (`pinta_db.job_db`, one per production area).

Load `nls-sql` for SQL and migration work, and `nls-python` for Python.

## Rules

- Register new models in `src/pinta_db/<primary|job>_db/models/all.py`, or
  autogenerate will not see them.
- Create migrations from this directory and pass the next zero-padded
  revision id (e.g. `011`):
  `uv run alembic -c migrations/<job|primary>/alembic.ini revision --autogenerate -m "..." --rev-id="011"`
- Review autogenerated migrations and remove Alembic's generated comments.
- Use a manual migration for roles, schemas and privileges.
- Never edit a migration that is already on `main`; add a new one instead.
- Never edit `docs/`; CI regenerates it with tbls and opens a PR automatically.
- Keep the base dependencies driver-free: psycopg3 lives in the `psycopg`
  extra so the QGIS plugin can stay on psycopg2.
- `scripts/create_development_users.sql` uses psql meta-commands and is
  excluded from sqlfluff.

## Tests

- Unit: `uv run pytest test_db`
- Integration (databases up and migrated with `make up db-migrate-all` at
  the repo root): `uv run pytest test_integration_db`
